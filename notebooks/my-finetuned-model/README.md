  - "Plagiarism Detection using BERT Embeddings and Cosine Similarity\n\nIntroduction\n\
    \nPlagiarism is a major concern in academic projects, as it undermines the integrity\
    \ and originality of student work. Traditional plagiarism detection tools primarily\
    \ rely on string matching, which fails to identify paraphrased or contextually\
    \ similar content. To address this, our project uses advanced Natural Language\
    \ Processing (NLP) techniques—specifically, BERT embeddings and cosine similarity—to\
    \ detect both exact and semantically similar plagiarism in student submissions.\n\
    \nBERT: General Working Principle\n\nBERT (Bidirectional Encoder Representations\
    \ from Transformers) is a powerful language model developed by Google. Unlike\
    \ earlier models, BERT can read text in both directions (left-to-right and right-to-left)\
    \ at the same time, allowing it to understand the deeper context and meaning of\
    \ each sentence.\n\nHow BERT Works\n\n- BERT takes an input text and processes\
    \ it through a series of transformer layers.\n- It produces a vector embedding—a\
    \ list of numbers that captures the meaning and context of the text.\n- Texts\
    \ with similar meanings will have embeddings that are close together in this multi-dimensional\
    \ space, even if the actual words differ.\n\nMathematical Expression:\n\nGiven\
    \ a text T:\n\nv = BERT(T)\n\nwhere v is an embedding vector in R^n (e.g., n =\
    \ 768 for base BERT).\n\nCosine Similarity: General Working Principle\n\nCosine\
    \ similarity is a mathematical method used to determine the similarity between\
    \ two vectors by measuring the cosine of the angle between them.\n\nHow Cosine\
    \ Similarity Works\n\n- If two vectors point in the same direction, their cosine\
    \ similarity is 1 (high similarity).\n- If they are perpendicular, their similarity\
    \ is 0 (no similarity).\n- If they are opposite, their similarity is -1 (completely\
    \ different; rare in text).\n\nMathematical Formula:\n\nGiven vectors a and b:\n\
    \nCosineSimilarity(a, b) = (a · b) / (||a|| × ||b||)\n\nwhere · is the dot product,\
    \ and ||a|| is the magnitude of vector a.\n\nHow My Project Uses BERT and Cosine\
    \ Similarity\n\nStudent Submissions:\nStudents submit their project reports through\
    \ the system.\n\nEmbedding Generation (BERT):\nEach document is passed through\
    \ a pre-trained BERT model to obtain a unique vector embedding representing its\
    \ semantic meaning.\n\nSimilarity Computation (Cosine Similarity):\nThe system\
    \ compares every pair of document embeddings using cosine similarity.\n\nPlagiarism\
    \ Detection:\nIf the similarity score between two documents is above a certain\

# SentenceTransformer based on sentence-transformers/all-MiniLM-L6-v2

This is a [sentence-transformers](https://www.SBERT.net) model finetuned from [sentence-transformers/all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2). It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, text classification, clustering, and more.
